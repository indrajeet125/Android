# Android Learning Workspace

This repository contains a collection of Android projects created for learning, practice, and experimentation in both Java and Kotlin.

## Project Structure

### AndroidWithJava
This folder contains Java-based Android applications covering a wide range of topics such as:

- Activity lifecycle
- Firebase integration
- RecyclerView and ListView
- UI/UX components
- Contact management
- Calculator and BMI apps
- Date picker, media player, web view, and camera-related examples
- Student management, URL handling, and upload features

### AndroidWithKotlin
This folder contains Kotlin-based Android projects focused on modern Android development concepts, including:

- Camera permission handling
- Location-based services
- Weather app
- Clean Architecture-based note app
- Happy Places app
- Kotlin practice and sample app modules

## Purpose

This workspace is intended for:

- Android practice and revision
- Learning Android app architecture and components
- Trying different UI and backend integrations
- Building small real-world app examples

## Getting Started

1. Open the project in Android Studio.
2. Choose either the Java or Kotlin workspace depending on the app you want to run.
3. Let Gradle sync the project.
4. Connect an emulator or Android device and run the app.

## Notes

- Some projects may be independent mini-apps and can be opened as separate Android Studio projects.
- The workspace is suitable for learning and experimentation rather than a single production app.
